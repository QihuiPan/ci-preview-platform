# CI Preview Platform 0.2.0

This release replaces the original simulator with a usable small-team self-hosted runtime: encrypted PostgreSQL state, authenticated repository-scoped APIs, actual Kubernetes jobs, retained logs/artifacts, and readiness-driven preview environments.

## Downloads and installation

Download the matching cictl binary, START_HERE.md, and SHA256SUMS from the release assets. Windows, Linux, and macOS builds are available for AMD64 and ARM64. The source ZIP contains Dockerfiles, examples, and full documentation; the Helm chart is also packaged separately.

Follow the [installation guide](https://github.com/QihuiPan/ci-preview-platform/blob/v0.2.0/docs/installation.md). A dedicated Linux Kubernetes cluster, enforcing CNI, persistent storage, and pullable platform/MinIO images are required. This is not an already hosted website.

## Before deployment

Back up the database and exact state key before upgrades. Version 0.1 was an in-memory simulator and has no durable state migration path. Generate complete 0.2 credentials once; never regenerate an existing state key casually.

GitHub App installation, private registry publishing, and public DNS/TLS require owner configuration and credential-dependent acceptance. The release does not claim a hostile-multi-tenant SaaS boundary, high availability, a browser dashboard, autoscaling, or Argo CD integration. A private GitHub repository still requires collaborator access for downloads.

All source comments, documentation, and changelog entries are in English. Every change commit includes a CHANGELOG.md update. The platform source is MIT-licensed; the separate MinIO component is AGPL-3.0-or-later.
